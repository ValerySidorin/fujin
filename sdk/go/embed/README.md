# Fujin Go Embedding SDK

Package `github.com/fujin-io/fujin/sdk/go/embed` loads a Fujin `cdylib` generated by
`cargo-fujin`. The library contains the selected Rust plugins; Go controls application startup,
readiness, connector snapshots, status, and shutdown through Fujin C ABI v1.

This is an embedding API, not a client for the Fujin native or gRPC wire protocols.

## Build the library

Set the manifest artifact to `cdylib` and select every plugin the embedded application may use:

```toml
[application]
name = "my-fujin"
artifact = "cdylib"

[fujin]
version = "0.6.0"

[[plugins.transport]]
name = "tcp"
package = "fujin-transport-tcp"
version = "0.6.0"
```

Build it with `cargo fujin build` (release is the default profile). The command prints the
resulting `.so`, `.dylib`, or `.dll` path. Build the library for the same operating system and
architecture as the Go process.
The Go package uses cgo; a supported C toolchain and `CGO_ENABLED=1` are required.

By default, `cargo-fujin` retains the generated Cargo project and `target/` cache for fast
incremental rebuilds; unchanged generated sources are not rewritten. Use `cargo fujin clean` to
remove that cache without deleting the installed library, or add `--clean-after` to `build` when a
one-shot build should leave only the configured output artifact.

Plugin composition is fixed at library build time. Runtime configuration can select only plugins
compiled into that library.

## Runnable example

The [`examples/basic`](examples/basic) host owns signal handling, starts a TCP listener on an
ephemeral port, prints the ready endpoint, and performs bounded graceful shutdown. From the Fujin
repository root:

```bash
cargo run -p cargo-fujin -- \
  --manifest sdk/go/embed/examples/basic/fujin.build.toml \
  build --profile dev

cd sdk/go/embed
go build -o ./examples/basic/.fujin/embed-host ./examples/basic
FUJIN_LIBRARY_PATH=./examples/basic/.fujin/libfujin_embed_example \
  ./examples/basic/.fujin/embed-host
```

Press Ctrl-C to exercise the host-owned shutdown path. `cargo-fujin` prints the generated library
path; use that exact path if an output override or platform packaging changes it.

## Start and stop

```go
package main

import (
    "context"
    "log"
    "time"

    fujin "github.com/fujin-io/fujin/sdk/go/embed"
)

func main() {
    library, err := fujin.Open("./libmy_fujin.dylib")
    if err != nil {
        log.Fatal(err)
    }
    defer library.Close()

    config := fujin.RuntimeConfig{
        Fujin: fujin.FujinConfig{Transports: []fujin.TransportConfig{{
            Type: "tcp",
            Settings: map[string]any{"addr": "127.0.0.1:4848"},
        }}},
        GRPC: &fujin.GRPCConfig{Enabled: false},
        Connectors: map[string]fujin.ConnectorConfig{},
    }

    application, err := library.Start(context.Background(), fujin.Options{
        Config: &config,
    })
    if err != nil {
        log.Fatal(err)
    }
    defer application.Close()

    endpoints, err := application.Endpoints()
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("ready: %+v", endpoints)

    shutdownContext, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()
    if err := application.Shutdown(shutdownContext); err != nil {
        log.Fatal(err)
    }
}
```

`Start` returns only after every configured listener reports ready. When `Options.Config` is nil,
the generated library uses its selected configurator. A startup context cancellation cannot cancel
a native call already in progress; `Start` returns the context error and asynchronously closes the
application if native startup subsequently succeeds.

`Application.Done` closes on terminal runtime exit. `Wait` returns the terminal error. `Shutdown`
requests graceful shutdown and respects its context while waiting, but does not release the native
handle. `Close` waits without a deadline, frees the handle, and is safe to call more than once.
Close every application before calling `Library.Close`; the library rejects unloading while an
application remains active.

Embedded mode does not install process signal handlers. The host owns `SIGINT`, `SIGTERM`, and
`SIGHUP` policy and should call `Shutdown`, `ReloadFromConfigurator`, or `ReloadConnectors` as
appropriate. `Options.GracefulUpgrade` is false by default and should remain false unless the host
explicitly coordinates Fujin's Unix binary-upgrade machinery.

The SDK copies ABI JSON and error messages into Go memory and frees their native buffers before
returning. The only native resources retained by callers are `Application` and `Library`; release
them in that order. Application methods are synchronized for concurrent Go callers, although
`Close` waits for in-flight operations before freeing the handle.

ABI v1 never calls back into Go. Connector callbacks, broker clients, and protocol sessions remain
inside the generated Rust library. The host is responsible only for configuration, lifecycle,
process policy, and consuming standard-error logs.

## Runtime control

- `Endpoints` returns the native, gRPC, and health listeners that completed startup.
- `Status` returns connector revision, source connectivity, and generation drain state.
- `WatchesConnectors` reports whether the configurator owns runtime connector state.
- `ReloadConnectors` submits a complete connector snapshot; it is not a patch.
- `ReloadFromConfigurator` reuses the retained bootstrap configurator.

Runtime connector revisions are monotonic. A successful result means local compilation and
publication succeeded; it does not prove broker reachability. Existing sessions remain pinned to
the connector generation selected at bind time.

Plugin-specific transport and connector settings use `any` because their schemas are defined by the
statically linked Rust plugin. Invalid or unknown settings fail through `Start` or the reload result.

## Errors

Native failures are returned as `*fujin.StatusError`. `Status` is one of `StatusInvalidArgument`,
`StatusStartFailed`, `StatusRuntimeFailed`, or `StatusPanic`; `Message` contains the owned Rust error
text copied before the ABI error is freed. Operations after handle release return `fujin.ErrClosed`.
A panic in Rust is caught at the ABI boundary and reported as `StatusPanic`; it never unwinds into Go.

## Logging

The embedded library writes Rust `tracing` events to the host process standard error. Configure it
before the first `Start` call:

- `FUJIN_LOG_LEVEL=DEBUG|INFO|WARN|ERROR|OFF` (default `INFO`)
- `FUJIN_LOG_TYPE=json` for newline-delimited JSON; any other value selects text output

Logging initialization is process-global and first-call-wins. If the process already installed a
compatible Rust `tracing` subscriber, Fujin leaves it in place. Embedded mode does not reload the
filter on `SIGHUP` and the Go SDK does not currently expose a log callback.
